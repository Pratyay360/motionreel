# a small html and js script to make sharable videos out of motion reel videos

just copy the html from your motion reel generated by llm


pleae install [mise](https://mise.run) to manage dependencies

and with nodejs install 

paste it into the script block of index.html

```js
window.__reel={
  DUR,
  get time(){return T;},
  rebuild(){build();apply(T);},
  seekTo(t){
    playing=false;ended=false;
    replay.classList.remove('show');
    document.body.classList.remove('hidechrome');
    seek(t);apply(T);
  }
};

```

```bash
npm i
npx playwright install
npm run capture
```

you can also run this containerized using docker/podman/buildah  too
